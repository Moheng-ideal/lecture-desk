# 讲课台

讲课台是一款面向平板备课、自学和课堂讲解的应用。横屏时，左侧阅读、批注课件，右侧是 DeepSeek 讲解师。拖动分隔线可调整两侧宽度，白板可作为应用内小窗打开。

## 主要功能

- **课件阅读与批注**。可批量导入 PDF、Word 和 PPT，通过标签页切换课件。支持连续滚动、双指缩放、触控笔批注和框选截图。可以双击标签页改名，或让 AI 读图建议名称。带批注的课件可导出为 PDF 或上传飞书云盘。
- **白板**。点顶部「白板」打开浮动小窗，默认在讲解区打开。拖动标题栏移动小窗，松手即停。点顶部「白板」可随时复位。拖左右下边或四角可调整大小。小窗外的课本与讲解区仍可操作。白板画布支持平移、缩放、压感笔刷以及点擦、整笔擦和圈选擦除。
- **笔快捷工具**。点顶部「笔工具」，可在最近用笔接触的区域选择现有工具。Android 版也可通过系统转发的手写笔侧键打开工具盘。
- **DeepSeek 讲解师**。可直接分析课件截图或讲解当前页，每次提问最多带 8 张截图。内置公式排版和教学示意图，公式随回答生成显示。可设置自定义提示词和用户画像。Android 版支持按住录音，松手后由 DeepSeek 转写并提问。
- **问答录**。问题、课件截图、历史文字引用和 AI 回答可按课本折叠查看，支持整本或逐条选择，导出为 Word 或保存为可编辑的飞书云文档。

Android 和卓易通版可在「设置 → 检查更新」选择「从服务器下载」或「从 GitHub 下载」。按系统提示覆盖安装可保留本机课本、批注、问答和设置。在设置中展开「更新日志」可离线查看版本改动。

阅读、批注和白板可离线使用。首次使用讲解师时，在「设置」填写 DeepSeek API Key，后续打开应用会自动读取。飞书配置可在设置中查看「如何接入飞书」。

## 浏览器版使用

1. 用华为浏览器打开讲课台。横屏后点「导入 PDF」，在系统文件选择器中选择课本。可通过华为浏览器菜单将此页面添加至桌面。
2. 选择「批注笔」或「荧光笔」，用 M-Pencil 书写。可调颜色和粗细，用橡皮擦除整笔，或撤销及重做。默认触控笔书写，手指拖动滚动。若浏览器将笔识别为手指，在设置中开启「允许手指书写」，用「阅读」模式滚动。
3. 点「选文」，在课本上拖框，再点「添加截图」。可连续添加并预览多张截图，然后统一发送。点「讲解本页」可附上整页截图并提问。
4. 完整回答会自动收入「问答录」，可以按课本折叠查看。点「仅选本书」可以整本导出，也可以逐条勾选。问答录可保存为 Word 或可编辑的飞书云文档。

浏览器在当前设备、当前网址保存课本、页码、批注和问答。改用另一台设备或清除站点数据会使用不同的书架。DeepSeek 收到问题、选取的截图和此书近期对话。点「AI 总结命名」时会发送课本首页及另一页截图。飞书会收到你勾选的问答和随附截图。

## 配置连接

- **DeepSeek**。在应用、HTTPS 版或当前电脑的 `localhost` 打开「设置」，填入 DeepSeek API Key。密钥加密保存在本机，重新打开后自动读取。清空密钥并应用设置即可移除。 [DeepSeek 平台](https://platform.deepseek.com/)
- **飞书**。在 [飞书开放平台](https://open.feishu.cn/app) 创建企业自建应用，开通「创建及编辑新版文档」权限 `docx:document` 并发布应用。含截图的问答录还需开通上传素材相关权限。让应用具备目标飞书云空间文件夹的可编辑权限，在「设置」中填入 App ID、App Secret 及 `/drive/folder/…` 文件夹链接。保存成功后，可以打开返回的云文档链接。若提示部分写入失败，保持原有标题和勾选项，再点「继续保存」。

## 本机或同一 Wi-Fi 运行

需要 Node.js 22.12 或更高版本。

```powershell
npm ci
npm run build
npm start
```

电脑访问 `http://127.0.0.1:8787`。要让华为平板通过同一 Wi-Fi 访问，将 [环境变量样例](.env.example) 复制为项目目录下的 `.env`。设置 `TEACH_HOST=0.0.0.0`，填写至少 12 个字符的 `TEACH_PASS`，并把 DeepSeek 和飞书凭据放在电脑的 `.env` 中。重新运行 `npm start`，在平板上访问终端打印的局域网地址，并输入访问口令。局域网 HTTP 用于可信网络。

```powershell
npm test
git log --oneline
git tag --list
```

通过 Git 提交并打版本标签。`.env`、编译产物、课本和个人问答数据均不进入版本库。

Android APK 可用「按住说话」按钮录音，松手后由 DeepSeek 转写并直接向讲解师提问。按住时向上滑，看到「松手取消」后松手即可丢弃录音。首次使用需要允许麦克风权限，并在设置中填写现有的 DeepSeek API Key。单段录音最多 30 秒，松手后上传，DeepSeek 按音频时长计费。 [DeepSeek 语音转文字](https://api-docs.deepseek.com/guides/asr/)

内置示例课本为原创，用 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 字体生成。样书和快捷方式图标可以用 `scripts/sample.py` 重新生成，参数为 Noto Sans SC TrueType 字体路径，需要 ReportLab、Pillow 和 FontTools。
