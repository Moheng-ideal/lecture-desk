## 一、右侧问答区截图（📋 待决策）

### 需求

右侧讲解师的回答目前只能**框选提取文字**（生成「问答摘录」引用）。希望能**截图**右侧区域，把画面（含公式、图表、排版）插入笔记。

### 三个候选方案

#### 方案 A：Android 系统截屏（MediaProjection）

真正的"调用系统截图工具"。

```
WebView 请求 → 系统授权弹窗 → 前台服务捕获屏幕
           → 裁剪右侧区域 → 图片传给笔记
```

| 项 | 情况 |
|---|---|
| 实现成本 | **高**：MainActivity + MediaProjection + 前台服务（Android 14 强制 `mediaProjection` 类型） |
| 用户操作 | **每次**截屏都要系统弹窗授权（Android 14 起不能长期授权） |
| 兼容性 | Android 10+ 可行；卓易通 / WebView 环境需真机验证 |
| 效果 | 截到整屏内容（含面板边框、阴影），需要额外裁剪 |
| 工作量 | 约 2-3 小时（含真机调试） |

#### 方案 B：前端 DOM 截图（html2canvas 类）

纯 WebView 内完成，不碰原生。

| 项 | 情况 |
|---|---|
| 实现成本 | **中**：引入库 + 配置（CSP 已允许同源脚本） |
| 效果 | 文字/布局准确；**KaTeX 公式**（SVG 渲染）可能失真或丢失 |
| 权限 | 无需系统权限 |
| 体积 | 增加约 200 KB |
| 工作量 | 约 1-2 小时 |

#### 方案 C：系统截图 + 相册导入（最省事）

用户用平板自带截屏快捷键（如三指下滑）→ 图片进相册 → 笔记「插入图片」从相册选。

| 项 | 情况 |
|---|---|
| 实现成本 | **低**：加"从相册选图"入口（原生文件选择器） |
| 用户操作 | 手动截屏 + 选图（多一步） |
| 效果 | 100% 真实截图，公式/图表完美 |
| 工作量 | 约 1 小时 |

### 决策所需信息

1. 主要使用设备：平板（APK）还是电脑浏览器？
2. 右侧内容里公式多不多？（多则 A/C 更优，B 会失真）
3. 能否接受每次截屏弹系统授权窗？（A 的代价）

### 建议

| 优先级 | 选 |
|---|---|
| 必须程序内一键截屏 | A |
| 要公式/图表完美、能接受多一步 | C |
| 纯网页版也要能用、可接受公式失真 | B |

## 二、笔记导出 PDF（🔨 待开发）

### 需求

把笔记（多页）导出为 PDF 文件。

### 方案

用项目已有依赖 `pdf-lib@1.17.1`：

```
每页 → 渲染到 canvas（背景 + 图片 + 笔迹 + 文字）
     → canvas.toDataURL('image/png')
     → pdf-lib embedPng + addPage(A4)
     → 保存/下载
```

| 项 | 说明 |
|---|---|
| 依赖 | 已具备（pdf-lib） |
| 工作量 | 约 1-2 小时 |
| 注意 | 背景纹理需重绘（canvas 里画横线/方格/点阵）；文字需用 canvas fillText 渲染（或截图 DOM） |

### 待确认

- 导出后保存位置：下载文件？飞书？还是两者？
- 页面尺寸：A4 标准（595×842 pt）
