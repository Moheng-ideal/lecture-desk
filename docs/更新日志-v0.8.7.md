# 讲课台 v0.8.7 · 南开校园版

> NK-GeniOS 接入 + 视觉读图

- 接入南开 NK-GeniOS 智能体：密钥不以 `sk-` 开头时，讲解自动走校园免费智能体；`sk-` 开头的 DeepSeek 密钥保持原有行为。
- 新增「视觉模型 API Key（可选）」：填写后截图由智谱 GLM-4V-Flash 直接识图，公式和图表可见；不填写时桌面端用本机 OCR 把截图转成文字后交给智能体。
- 选文支持右侧问答区：同一把「选文」工具可在讲解师回答上框选，生成「问答摘录」文字引用，可继续追问；课本侧仍生成截图。
- 修复视觉模型在回答结尾自问自答的问题，检查理解的问题只提给学生。
- 连接状态按密钥类型显示 NK-GeniOS 或 DeepSeek，并标注是否已配置视觉模型。
- 平板等没有本机 OCR 的环境，截图提问未配置视觉模型时给出明确提示，而不是返回空回答。

## 配置说明

在「设置」中填写：

| 输入框 | 填写内容 |
| --- | --- |
| DeepSeek / NK-GeniOS API Key | NK-GeniOS 教学智能体密钥，或 `sk-` 开头的 DeepSeek 密钥 |
| 视觉模型 API Key（可选） | 智谱 GLM-4V-Flash 密钥；留空则截图走本机 OCR |

## 已知限制

- 视觉模型（GLM-4V-Flash）单次回复上限 1024 tokens，长讲解需要继续追问。
- 免费视觉模型有并发限制，高峰期可能提示请求过于频繁。
- Android 端没有本机 OCR，截图提问需要配置视觉模型 Key。
