# 更新日志

## v0.8.9 · 课本缩放与工具栏改进

- 修复课本缩放后偶发缺字的问题。重绘完成后再刷新页面，批注随页面一起缩放。
- 调整工具栏按钮反馈。白板、笔记等按钮按下变色，松手立即恢复。
- 课本、白板和笔记里，单点画笔、荧光笔或橡皮可切换工具，双点打开对应设置。
- 在「添加截图」左侧新增「退出选文」。退出课本和问答区的框选后，已添加的截图与摘录会保留。
- 课本和白板使用左、右弯箭头撤销和复原。一次连续擦除算一步，白板清空也能撤销和复原。
- Android 版默认隐藏上下系统栏，可从屏幕边缘滑动临时呼出。

## v0.8.8 · 笔记功能

- 白板右侧新增「笔记」按钮：浮动可拖动、可缩放的笔记窗口，与世界白板并列使用。
- 支持同时创建多篇笔记：新建、切换、重命名、删除，内容保存在本机并自动保存。
- 手写直接复用课本批注的笔刷引擎：圆珠笔、钢笔、签字笔、毛笔、荧光笔，可调粗细、不透明度和颜色。
- 橡皮支持点擦连续擦除与套索擦除；套索为切割式（只去掉框内那一段，框外保留），课本、白板、笔记三处行为与轨迹样式统一。
- 多页纵向滚动，滚到底部自动追加空白页；可单独删除空白页或一键清除所有空白页。
- 页面背景支持横线、方格、点阵、空白四种。
- 可直接插入课本截图：左侧框选后点「插入截图」即插入当前页，也可从引用区列表选择；截图可拖动、跨页移动、拖手柄缩放、工具条删除。
- 可插入右侧讲解师回答的「问答摘录」：作为文字框放进当前页，支持双击编辑、拖动、调整字号与字体颜色。
- 「文字」按钮添加文本框，空框显示「请输入文本」占位；双击进入编辑，工具条可改字号和颜色。
- 笔记可导出为 A4 PDF：背景、截图、文字与手写笔迹按页面合成输出。
- 白板收回后再次打开恢复上次调整的大小，位置复位到默认；新增「重置大小」按钮，只重置窗口尺寸、不清空笔迹。
- 修复白板「允许手指书写」在设置中开启后仍不生效的问题（沿用 v0.8.6 的修复）。

## v0.8.7 · 南开校园版（NK-GeniOS + 视觉读图）

- 接入南开 NK-GeniOS 智能体：密钥不以 `sk-` 开头时，讲解自动走校园免费智能体；`sk-` 开头的 DeepSeek 密钥保持原有行为。
- 新增「视觉模型 API Key（可选）」：填写后截图由智谱 GLM-4V-Flash 直接识图，公式和图表可见；不填写时桌面端用本机 OCR 把截图转成文字后交给智能体。
- 选文支持右侧问答区：同一把「选文」工具可在讲解师回答上框选，生成「问答摘录」文字引用，可继续追问；课本侧仍生成截图。
- 修复视觉模型在回答结尾自问自答的问题，检查理解的问题只提给学生。
- 连接状态按密钥类型显示 NK-GeniOS 或 DeepSeek，并标注是否已配置视觉模型。
- 平板等没有本机 OCR 的环境，截图提问未配置视觉模型时给出明确提示，而不是返回空回答。

## v0.8.6 · 回滚至 v0.8.3

- 版本号升至 v0.8.6，已安装 v0.8.4 或 v0.8.5 的用户可覆盖安装，保留本地课本、批注、问答和设置。

## v0.8.5 · 卓易通笔身按键测试版

## v0.8.4 · 笔身双击测试版

- 设置中显示当前版本和应用自带的更新日志。

## v0.7.3 · 2026-11-23

- **按住录音，松手发送**。Android 和卓易通版可在讲解区按住「按住说话」。松手后由 DeepSeek 转写，转写结果自动发给讲解师，已输入的文字草稿会保留。
- **录音反馈**。麦克风开始录音后，按钮亮起并显示录音状态。在设备支持时会短振一下。
- **使用条件**。首次使用需要授权麦克风，转写沿用已有的 DeepSeek API Key。单段录音最多 30 秒，松手后上传，按录音时长计费。

## v0.7.2 · 2026-11-23

## v0.7.1 · 2026-11-23

- 白板改为应用内浮动小窗。拖动标题栏移动，拖任意一角调整尺寸。收起后会记住位置和大小。
- 右栏用于讲解，小窗开启时课本和讲解区的布局保持原有比例。白板保留触控笔书写、手指平移和双指缩放。

## v0.7.0 · 2026-11-23

- **选文改为截图**。在 PDF、Word 或 PPT 中框选文字、公式、图表或插图，点「添加截图」。发送前可预览或移除截图，每次提问最多附 8 张，由 DeepSeek Flash 直接读图。「讲解本页」也支持发送整页截图。
- **课本重命名**。双击标签页的书名，或从书架点「重命名」。也可点「AI 总结命名」，让 DeepSeek 根据首页及另一页截图给出建议。名称可自行编辑，保存后重启仍有效。
- **问答录保留截图**。课本改名后，已有问答随新名称归类。新问答可展开预览截图，导出 Word 或保存到飞书时会附上原图。历史文字引用仍可查看。飞书保存截图需要开通素材上传权限。
