    飞书云文档
    如何接入飞书
    1. 在开发者后台选择「创建企业自建应用」。打开飞书开放平台
    2. 在应用的「权限管理」中开通「创建及编辑新版文档」（docx:document），在「添加应用能力」中启用机器人，再到「版本管理与发布」发布应用。
    3. 在飞书建一个内部群，把应用加为群机器人。在云空间找到问答录要存入的文件夹，将它分享给该群，权限设为「可管理」。查看飞书授权说明
    4. 从应用的「凭证与基础信息」复制 App ID 和 App Secret。打开目标文件夹，从浏览器地址栏复制带有 /drive/folder/ 的完整链接。

    把三项填到下方，点「应用设置」，再到「问答录 → 保存到飞书」试存一条。

    局域网 HTTP 使用电脑端的 .env。依次填写 FEISHU_APP_ID、FEISHU_APP_SECRET 和 FEISHU_FOLDER_URL，重启服务，在平板输入访问口令后试存一条。
